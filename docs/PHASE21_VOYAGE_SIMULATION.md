# Phase 21 — 항로 시뮬레이션 1차

사용자 요청(2026-09-12): 해운 시뮬레이션으로의 확장 가능성을 설명하고 다음 단계를 실행한다.
핵심 업무를 항로와 출항 시각에 따른 해상조건 분석으로 확정했다.

## 구현한 기능

`/console?view=voyage`의 항로 시뮬레이션 탭에서 2–20개 웨이포인트, UTC 출항,
일정 대지속력(SOG), 사용자 파고 비교선을 입력한다. 예제·지도 추가·수동 좌표 입력이 가능하다.

- WGS84 타원체 측지선으로 구간 거리, 누적 해리, 침로를 계산한다.
- 이동 거리/SOG로 통과 시각과 도착 예정시각을 계산한다. 경유점에서는 즉시 침로가 바뀐다고 가정한다.
- 이동 위치·시각의 Hs, Tp, Tm02, 평균/첨두파향과 상대 파향을 조회한다.
- 기준, 6시간 지연 출항, 2 kn 감속 시나리오를 비교한다.
- 지도 선박 재생/시각 이동, 파고 초과 구간 색, 이동 파고 추세, 구간별 표와 파고 검증 근거를 표시한다.
- CSV는 모든 시나리오의 구간 값과 식별자·출처·조건·결측을 기록한다.
  JSON은 전체 입력·응답·계산 방법·엔진 속성·분석 시각·UUID를 보존한다.
- 입력 불러오기는 저장 파일의 입력을 복원하며, 현재 선택 예보로 다시 계산한다는 사실을 알린다.
  원본 분석 전체는 JSON 자체에 남는다. 서버 분석 이력/사용자별 저장소는 구현하지 않았다.
- 입력 변경 시 이전 결과는 재계산 전까지 내보내기/재생을 막고, 늦게 도착한 이전 요청 응답을 버린다.

## 계산 규약과 경계

`POST /v1/voyage/analyze`, 요청/응답 전체 계약은 실행 중 `/docs`의 VoyageRequest를 참조한다.
입력은 시간대가 있는 날짜만 받는다. 속력 1–40 kn, 비교선 0 초과~30m,
최대 3개 시나리오, 총 3,000 nm와 시나리오당 168시간으로 로컬 계산량을 제한한다.

- 측지선: GeographicLib 2.1, WGS84, Karney(2013).
  https://geographiclib.sourceforge.io/html/python/code.html
  https://doi.org/10.1007/s00190-012-0578-z
- 파고: 기존 검증/서빙의 해양 마스크 정규화 공간 보간 + 시각 선형 보간. **물리 원값**이며 보정하지 않는다.
- 평균주기/평균파향: 공간과 시각에서 선형 모멘트를 먼저 보간한 뒤 공통 derive 함수로 유도한다.
- 첨두주기/첨두파향: 최대 해양 보간 가중치 격자 + 최근접 예보 시각, 시간 동률은 앞 시각.
  359°와 1°를 산술 평균하거나 다른 첨두 빈을 선형 보간하지 않는다.
- 시각/해역 밖, 해양 마스크 없음, 육지/천해, 에너지 없음은 결측이다. 외삽하지 않는다.
- 지도/예보 샘플 간격은 최대 5 nm 및 최대 1시간. 촘촘한 조회가 L1 0.25°/약 3시간 원자료의 해상도를 높이지 않는다.
- 초과 시간: 두 끝점의 Hs가 모두 있는 구간만 선형 교차점으로 적분한다.
  커버리지는 이 구간들의 시간 합/전체 항해시간이다. 결측 구간을 0파고 또는 무노출로 합산하지 않는다.
- 육지 검사: 별도 최대 1 nm 간격의 측지선 표본과 ETOPO 60″ 최근접 고도. 표본 중 고도≥0이면
  invalid_route, 화면에서는 재생 불가. 검사를 통과해도 공식 해도·수심 여유·작은 장애물·항행 규칙·통항분리대를 확인한 것은 아니다.

## 검증

- Python 비과학 회귀·통합: **188건 통과** (기존 169 + 신규 19).
- Node: **9건 통과** (기존 6 + 신규 3).
- 신규 검증: WGS84 적도 거리/경유점, 중복 좌표, 일정 속력 ETA, 공간·시간 결측,
  육지 0 혼입 방지, 359°/1° 순환, 모멘트 유도, 임계 교차 적분/결측 구간,
  항로 내부 육지 통과, 타임존 없는 출항/범위 오류, 실제 과거 예보와 시간 범위 밖 API.
- 물리 엔진은 동결 설정을 유지했다. 과학 테스트 91건은 이 변경에서 재실행하지 않았다.

## 가능한 확장과 아직 없는 기능

1. 실제 상선 업무: 항로 대안·출항창·도착 제약·기상 감속·대기시간을 포함한 계획 비교.
2. 선박 성능: 선형별 저항/추진/속력-출력 곡선, 적재·흘수·실선 관측이 있어야 연료·CO₂·실효 ETA를 산출/보정할 수 있다.
3. 최적 항로: 바람·파랑·해류·제한구역·ENC·통항 규칙과 선박 성능을 함께 비용/제약으로 사용해야 한다.
4. 선체 운동/작업성: RAO, 적재상태, 복원성, 운동/가속도 관측 검증이 필요하다. 지금은 6자유도 또는 구조 하중 해석기가 아니다.
5. 선대/관제: AIS와 실측 연계, 권한·감사 이력, 연속 수집·알림·운영 검증이 필요하다.

이 단계는 **환경을 따라 이동하는 항로 분석기**의 구현 완료다. 연료 모델·최적 항로·선박 조종성·충돌 회피·
항해 적합성 승인은 포함하지 않는다. Phase 20 산업 인수 게이트와 최신 데이터 공백은 여전히 남아 있다.
