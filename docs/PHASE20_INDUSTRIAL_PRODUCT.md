# Phase 20 — 산업 현장용 제품 기준으로 전환

요청: “HD현대 해양관측팀에서 사용할 정도의 수준” (2026-09-11).
목표 수준의 상향이며, HD현대의 내부 규격·인증·납품 승인으로 해석하지 않는다.
기존 지시 문서와 과거 요청은 참고 자료다. 사용자의 이번 요구를 완료 기준에 반영한다.

## 현재 판정

산업 실무 투입 불가. 연구용 엔진과 로컬 데모/분석 시제품이다.
테스트 258건 통과는 구현 회귀와 일부 과학 게이트 통과이지, 예보 정확도·가용성·보안·사용성의
산업 적합성 증명이 아니다. 자체 엔진을 바꾼다고 독립 관측·극한 조건 검증이 생기지 않는다.

보편적인 “해양팀 합격 RMSE”를 임의로 만들지 않는다. 실선 안전/인증 검증은 코드 테스트로 대체하지 않는다.

## 이번 구현 범위

공통 기반인 분석 콘솔을 먼저 구현한다. 지도·관심 지점·리드별 추세·출처/검증·운영 목록·
명시적 데이터 내보내기를 기존 실제 API에 연결한다. 시각적 목업이나 가짜 실시간 수치가 아니다.
기존 화면은 /legacy로 보존한다. 산업 적합성은 이 UI 변경으로 통과 처리하지 않는다.

이후 핵심 업무를 확정해 항로 분석 또는 관측 관제 또는 작업창 분석을 하나의 수직 기능으로 완성하고,
독립 검증·운영 인수시험·팀 접근 제어로 이어간다. 이 문서 자체를 제품 완성으로 보고하지 않는다.

## 구현 결과 — 2026-09-12 00:18 KST

- `/`와 `/console`을 새 해양 분석 콘솔로 연결했다. 기존 분석은 `/legacy`, 선교 시뮬레이션은 `/bridge`다.
- 관심 지점 최대 8개, 좌표 입력/지도 선택/삭제/저장, 리드별 Hs·Tp·첨두파향, UTC/KST,
  수치표와 CSV 내보내기를 실제 API에 연결했다. 표시 시간은 로케일에 의존하지 않는 YYYY-MM-DD HH:mm이다.
- CSV에는 UTC 생산/유효/출력 시각, 예보 기준, 좌표, 물리 원값, 보정 상태, 엔진 속성,
  결측 사유와 Hs 검증 적용 범위를 기록한다. 결측을 0으로 표시하지 않는다.
- 파향은 359°와 1°를 직선으로 연결하지 않으며 결측 구간을 그래프로 잇지 않는다.
- 최신/과거 사이클 전환, 전체 검증 지표와 리드별 성적, 입력/예보 가용성 목록을 연결했다.
  과거 예보를 현재 예보처럼 표시하지 않으며, 카탈로그 실행 이력과 프로세스 상태를 혼동하지 않는다.
- 관측 조회가 월 파티션 1개만 읽던 결함을 수정했다. 조회 구간과 겹치는 모든 월에서
  관측소별 최신 QC 통과·유한값만 선택하고 미래 시각은 제외한다. 관측 조회 실패와 관측 0건을 구분한다.
- API 서비스만 재기동했다. 기존 운영 계산 PID 90164는 유지했다. 물리 엔진은 변경하지 않았다.

## 확인한 결과

- Python 비과학 회귀/통합 테스트 **169 통과**, 과학 테스트 91건은 이번 UI/API 변경에서 재실행하지 않았다.
  이전 Phase 19에서 91건 통과했고 그 뒤 물리 엔진 변경은 없다.
- Node 데이터/차트 테스트 **6 통과**: 결측/입력값, 시간대 자정 전환, 과거 예보,
  CSV 출처/빈값, 파향 순환, 결측 구간.
- `/`, `/console`, `/legacy`, `/bridge`, JS/CSS 요청 모두 HTTP 200. 음수 관측 조회 기간은 422.
- 실제 브라우저: 1280×720, 390×844에서 가로 넘침 없음. 지도·파고 레이어 표시,
  예측 검증/운영 탭, 리드·시간대·파향 전환, 지점 입력/육지 거절, 수치표 25행 확인.
  작은 화면에서도 내보내기 버튼에 접근할 수 있다. 브라우저 크기는 점검 후 원복했다.
- 2026-09-12 00:10 KST 로컬 HTTP 점검 단일 측정: 메타 0.10초, 다변수 지점 1.25초.
  동시 사용자 부하·냉시작·p95 시험이 아니므로 서비스 수준 보장으로 사용하지 않는다.
- 2026-09-12 00:13 KST API: Hs 4,044표본/33개소/25사이클, 전체 RMSE 0.3608m.
  리드·해역을 섞은 전체 표본 지표이다. 품질 개선 또는 산업 합격 주장에 사용하지 않는다.
- 같은 조회에서 등록된 L1 28개, 강제장+경계가 있고 L1이 없는 사이클 35개,
  최신 L1 기준 20260906T18, 도메인 내 최근 48시간 유효 Hs 관측 0개소였다.
  이 상태로 실시간 해양 관측 서비스가 완성되었다고 말할 수 없다.

## 남은 완료 조건

위 완료 게이트는 여전히 미통과다. 항로·출발/도착시각별 해상조건, 실제 담당자 업무 인수,
독립 관측/극한 조건 검증, 관측 원천 복구, 연속 운영, 팀 인증/권한/감사 이력이 남아 있다.
이번 결과는 산업 제품으로 발전시킬 분석 기반이며 HD현대 내부 규격·인증·도입 승인을 뜻하지 않는다.
