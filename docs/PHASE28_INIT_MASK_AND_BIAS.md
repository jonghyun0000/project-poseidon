## 1. 리드 0 해상 셀 10.4% 영값 — 원인 확정

PHASE18 §5 에서 20260906T18 한 사이클로 발견하고 `[가설]`로 남긴 현상이다.

**재현**: 발행된 90개 사이클 전부에서 리드 0 해상 셀의 영값 비율이 **10.21~10.47%**. 날씨와 무관한 구조적 결함이다.
리드 1(3 h) 중앙 2.31%, 리드 2 0.61%, 리드 3 0.11%로 줄어든다.

**원인** (`poseidon/scheduler/wave_cycle.py` `wave_fields` → `regional.spectra_from_integrals`):
1. 초기장은 GFS-Wave `swh` 를 우리 0.25° 격자로 `xarray.interp`(겹선형) 한다
2. GFS-Wave 는 자기 육지에 NaN 을 둔다. 겹선형은 네 모서리 중 하나라도 NaN 이면 결과가 NaN 이다
3. `spectra_from_integrals` 가 `np.nan_to_num(hs, nan=0.0)` 으로 그 NaN 을 **0 으로** 만든다
4. 그 셀은 우리 격자(ETOPO, 수심 하한 10 m)에서는 바다다 → 파고 0 으로 출발하고, 물리가 약 3시간에 걸쳐 채운다

**검증**: 3개 사이클(20260906T18·20260920T00·20260924T12)에서 "리드 0 영값 해상 셀"과 "보간 결과가 NaN 인 해상 셀"이
**예외 없이 1:1 로 일치**한다(1,278/1,287/1,283셀, 어느 방향으로도 불일치 0).

영값 셀은 두 부류다.

| 부류 | 비율 | 뜻 | 고치는 법 |
|---|---:|---|---|
| 스텐실 오염 | 약 26% | 가장 가까운 GFS-Wave 점은 바다인데 보간의 다른 모서리가 육지 | 해상 정규화 보간(값·마스크 따로 보간 후 나눔) |
| 마스크 불일치 | 약 74% | GFS-Wave 는 그 근처를 아예 육지로 본다 | 채울 원천 값이 없다 — 외삽 방식은 **모델링 선택** |

이 프로젝트의 **일곱 번째 마스크 결함**이다(`docs/LESSONS.md` A-1). 앞의 다섯 건은 검증·중첩·GSE·서빙·강제장 경로였고
여섯 번째는 표시 경로(A2 로 Astra 에 배정)다. 이번은 **예보 초기화 경로**다.

## 2. 이 결함이 리드 0 편향에 얼마나 기여하는가

콜로케이션은 수심으로 만든 **고정 해상 마스크**를 쓴다(`collocate._grid_sea`). 그래서 초기 영값 셀도 바다로 취급되어
리드 0 보간에 0 이 그대로 섞인다.

관측소별 보간 스텐실의 영값 가중(해상 가중 중 영값 셀 몫)을 계산했다. 33개소 중 5개소가 닿는다.

리드 0 전체 편향 −0.193 m 중, 5개소를 빼면 −0.120 m 가 남는다. 즉 **리드 0 과소의 약 38%가 이 결함이고,

### 말할 수 있는 것

- 리드 **15–48 h 에 약한 과대가 있다.** 크기는 집계에 따라 **+0.03 ~ +0.10 m**. 하루를 빼도 사라지지 않는다
- 리드 51–72 h 과대는 **확정하지 않는다**
- 전체 편향은 가중 +0.052 / 사이클 중앙 +0.009 — **어느 한 숫자로 요약하지 않는다**

### 말할 수 없는 것

- **원인.** 바람 입력 과잉(Wu 1982 항력), DIA, 관측소 분포(대부분 연안 KMA) 모두 후보일 뿐이다 `[가설]`.
  이 프로젝트는 원인을 서둘러 정했다가 물리 변경 두 건을 헛한 이력이 있다(PHASE15·16)
- **신뢰구간의 정확도.** 사이클 군집 부트스트랩이지만 인접 사이클은 같은 기상을 공유해 독립이 아니다 — 실제 불확실성은 표보다 크다
- 해운 판단 구간(4 m 이상)은 여전히 표본이 없다 — 2.5–5 m 대역도 16일·1,850건뿐이다

## 4. 수정안 — 승인 대기 (분업 C4)

그래서 **게이트를 결과 보기 전에 여기 등록하고**, 승인 뒤 진단 실행(`out_tag`)으로 평가한다.

- (a) GFS-Wave 를 **해상 정규화 보간**한다(스텐실 오염 26% 해소)
- (b) 그래도 비는 해상 셀은 **가장 가까운 GFS-Wave 해상 값으로, 최대 1셀(0.25°) 거리까지만** 채운다. 그 밖은 0 을 유지한다
  (74% 중 얼마가 채워지는지는 실행 전 계측). 외삽 거리 한도는 관행값이며 동료심사 근거는 찾지 못했다 `[확인 필요]`

## 5. 재현

분석 스크립트는 이 대화의 임시 폴더에서 돌렸다. 핵심 계산은 위 표의 정의로 다시 만들 수 있다:
- 영값 비율: 각 사이클 zarr `hs` 에서 `sea = max_lead(hs) > 0.011`, `zero = (hs[0] <= 0.011) & sea`
- 원인 대조: boundary zarr `swh.isel(time=0).interp(latitude=lats, longitude=lons)` 의 NaN 과 `zero` 의 교집합
- 관측소 영값 가중: L1 격자 겹선형 4모서리 중 해상 가중에서 `zero` 셀 몫
- 편향: `filter_by_land` 통과 hs 표본, 사이클 단위 복원 추출 1,000회, `numpy.random.default_rng(20260927)`
