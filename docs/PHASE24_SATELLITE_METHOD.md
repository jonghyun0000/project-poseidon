# Phase 24 — 외해 위성 관측 대조 방법

이 검정은 NDBC 부이의 고정된 검정과 분리한 Sentinel-3A 외해 파일럿이다. 두 결과를 합산하지 않으며 전 지구 정확도 승인이나 산업 운용 인증으로 해석하지 않는다. 상위 NOAA 모델의 동화·개발 자료에서 완전히 독립한 검정이라고 단정하지 않는다. Poseidon의 관측 맞춤 학습이나 보정은 수행하지 않는다.

## 관측과 고정 예보 표본

- [NOAA RADS 무인증 HTTPS 미러](https://www.star.nesdis.noaa.gov/pub/sod/lsa/rads/data/)의 Sentinel-3A phase a, cycle 143/144 전체 목록을 고정 저장한다.
- 각 파일에서 처음 16 KB Range 헤더만 읽어 실제 `first_meas_time`, `last_meas_time`으로 선택한다. 수정 시각을 관측 시각으로 간주하지 않는다. 동시 요청은 최대 6개다.
- 기존 부이 검정의 2026-09-03T00부터 2026-09-10T00 사이클, 6/24/48/72/120시간 리드 중 2026-09-11T16:00Z까지 유효해진 33개 예보장을 읽기 전용으로 재사용한다. GRIB과 NPZ 해시를 모두 확인한다. 0시간 분석장은 제외한다.
- 예보 유효시각 ±30분과 겹치는 pass만 전체 NetCDF를 받는다. 원본 목록·헤더·NetCDF·해시·수집 시각·서버 수정 시각·센서 원래 제품명을 보존한다. 수집 중 NRT 파일의 revision이 바뀌면 별도 기록하며 실제 전체 파일의 메타데이터를 사용한다.
- 별도 `protocol.json`을 관측 수집과 예보 오차 산출 전에 기록한다. NDBC 검정과 운영 예보 캐시는 수정하지 않는다.

## 변수와 품질 조건

관측은 **센서 변수 `swh_ku` [m]만** 사용한다. 같은 RADS 파일의 `swh_mfwam`, `swh_ww3`, `swh_era5`는 모델값이므로 사용할 수 없다. 미지의 미션·단위·변수 정의·비트 의미는 전체 pass 오류로 기록하고 추정하지 않는다. CF scale factor와 fill value를 복원한 값을 사용한다.

공식 [RADS 변수 설정](https://raw.githubusercontent.com/remkos/rads/master/conf/rads.xml)과 [데이터 설명서](https://raw.githubusercontent.com/remkos/rads/master/doc/manuals/rads4_data_manual.pdf)에 근거한 별도 보수적 파일럿 조건:

1. 유효 UTC 시각과 위치, 같은 pass에서 중복 시각 전체 제외.
2. signed int16 flag를 결측 검사 후 unsigned 16-bit로 해석한다. `flags & 0xBFFE == 0`: `sar_mode`와 `not_used` 비트만 허용하고 명명된 나머지 품질 불량 비트는 모두 제외한다. 정상 SAR 관측은 flags=1일 수 있어 flags=0 조건은 틀리다. 이 마스크는 RADS 범용 기본값 0xFFA8보다 엄격한 파일럿 선택이다.
3. 유효한 `0 <= swh_ku <= 8 m`, `0 <= swh_rms_ku <= 2.1 m`.
4. `dist_coast >= 50 km`. 거리 양수는 외해, 음수는 육지다.
5. 관측 시각이 고정 cutoff 이내.

**8 m 초과 파고를 제외하는 조건은 큰 파고 표본을 잘라낸다. 따라서 이 검정으로 극한 파랑 정확도를 주장할 수 없다.** 0–8m 범위·2.1m RMS 상한은 RADS 설정값과 일치하되, 품질 보증이나 선박 안전 허용치가 아니다. 품질 규칙별 최초 탈락 행 수는 상호 배타적이며, 별도로 표기한 규칙 위반 수는 중복될 수 있다. 해빙·연안·저품질 상태의 정확도를 이 결과에서 추론하지 않는다.

## 구간 평균과 같은 표본 대조

원래 위치·시각 순서의 WGS84 누적 거리를 이용해 약 30 km 구간을 만든다. **파고나 QC 결과를 보기 전에** 구간 경계를 정한다. 위치/시각 결측, 시각 역전 또는 중복, 60초 초과 기록 공백에서는 새 구간을 시작한다. 날짜변경선 거리 계산도 WGS84로 처리한다.

예보 유효시각 ±30분과 품질 조건을 만족하는 표본이 구간마다 3개 이상 있어야 한다. 관측 평균과 각 표본 위치에서 실제 서비스의 `global_forecast.spatial()`로 추출한 Hs 평균을 대조한다. 구간 중심 한 점의 예보를 대신 사용하지 않는다. 선택된 표본 중 한 개라도 예보 해양 마스크에서 결측이면 구간 전체를 제외한다. 시간 보간은 수행하지 않는다. 오차는 `예보 평균 − 관측 평균`이다.

위치 요약은 첫·마지막 선택 표본의 WGS84 중점이다. 구역은 기존 좌표 구분 `global_metrics.region()`을 사용하며 정밀 해양 분지 다각형이 아니다. 구역별 0표본도 표시한다.

## 통계와 재현

RMSE, MAE, bias는 구간·예보 사이클 쌍 가중 기술통계다. 같은 관측 구간이 다른 예보 사이클에 반복 사용되는 수와 서로 다른 관측 구간 수, 궤도 수, 관측 날짜 수, 유효시각 수를 구분한다. 약 30 km 평균을 해도 인접 구간·날짜·예보는 상관되므로 독립 실험으로 세지 않는다. 이 파일럿은 신뢰구간을 산출하지 않는다.

실행:

```sh
.venv/bin/python -m poseidon.validation.global_altimeter
.venv/bin/python -m poseidon.validation.global_altimeter --resume RUN_ID --offline
```

각 실행은 `data/validation/global_altimeter/runs/RUN_ID/`의 새로운 불변 `protocol.json`, `observations/`, `pairs.csv`, `report.json`을 만든다. 오프라인 재현은 기존 관측 스냅샷과 예보 해시를 검증하고 새로운 결과를 생성한다. 작업이 완전히 끝난 뒤에만 `latest.json`을 바꾼다. 실패하면 이전 결과를 보존한다.

자료 출처: [NOAA RADS 운영·형식 설명](https://coastwatch.noaa.gov/cwn/data-access-tools/rads-utilities.html). Altimetry data are provided by the NOAA Laboratory for Satellite Altimetry. NOAA CoastWatch를 인정 표기한다.
