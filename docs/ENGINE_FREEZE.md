# 엔진 설정 동결 선언 (Engine Freeze)

**동결 시각:** 2026-08-23 (KST) · **대상:** 파랑 전파 엔진 수치 설정
**목적:** 표본 재생산(B-1) 이전에 산출물의 출처를 고정한다. 동결 이후 이 값을 바꾸면
기존 error_sample·forecast zarr이 전부 낡으므로, 변경 시 재생산이 의무다.

## 동결된 값

| 항목 | 값 | 근거 |

| `advection` | **`"uno2"`** | Li (2008) 2차 비진동, WW3 `UNO` 계열. 수치확산 L1 −79%/L2 −96%, 에너지보존 24배·위상오차 6배 개선, 단조성·양수보존 완벽(클립 발동 0회). `"upwind"` 폴백은 비트 동일 복원 가능 |

## 미결로 남긴 것 (동결 대상 아님)
- **CAL_CDS 등 소스항 보정 상수** — 잔여 저편향의 84%가 경계(GFS-Wave bias −0.126 m)에서
  오므로 소스항으로 흡수하면 "Δx 종속"을 "경계편향 종속"으로 바꿔 다는 것뿐이다.
  올바른 순서: 다중 사이클 재측정 → 경계 편향 분리 보정 → 그 다음 재튜닝.
- **M7 게이트 15%** — 오염 데이터로 물리 편향이 −0.075로 부풀려졌을 때 정한 값.
  현재 −0.047이므로 기준 재검토 필요.

## 해제 조건
다음 중 하나가 확인되면 동결을 해제하고 재생산한다:
1. 장기 리드(72 h+)·스웰 지배 사례에서 GSE 아티팩트가 실측으로 확인될 때
2. 경계 편향 분리 보정이 도입되어 CAL_* 재튜닝의 전제가 갖춰질 때
3. 이류 스킴의 결함이 발견될 때
