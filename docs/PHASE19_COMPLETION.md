# Phase 19 — 로컬 실행 복구와 예보 표시 완성 작업

기준: 2026-09-11, 실제 로컬 저장소와 브라우저. 전체 상업 항해 제품의 완성 판정이 아니다.

## 구현

- 기존 index.html의 지도 레이어 객체 닫는 괄호가 한 줄 주석에 묻힌 문법 오류 수정.
  이 오류는 JS 전체 실행을 막았다. Python 테스트는 통과해도 화면은 초기 상태에 머물렀다.
- 점 예보 `vars=hs,tp,tm01,tm02,dirm,dirp`, `level=auto|L1|L2` 지원.
  기존 `items[].q50/physics_raw`는 호환 유지, 추가 변수는 `items[].values`와 `missing`에 표시.
  평균량은 선형 모멘트를 해상 정규화 보간한 뒤 유도한다. 첨두량은 최대 해상 보간 가중치 셀을 사용한다.
  미저장 변수는 null로 반환하며 상수로 대체하지 않는다.
- UTC 오프셋을 점 예보·격자 메타·선교 API에 명시. 리드별 `applicability` 추가(파고 성적만 해당).
- 고정 지점 시간표에 파고·첨두주기·첨두파향, 선택 리드의 검증 범위를 표시.
  시간표는 L1을 명시해 지도와 해상도를 맞춘다. 항로 시간표가 아니다.
- 파고 이미지 확대는 육지 0을 섞는 bicubic 방식에서 해상 가중치 정규화로 변경.
- 주간·박명·야간 수동 전환. 선교에 선폭·흘수 입력 추가.
- 운영 루프에 로컬 미예보 입력 및 최근 원천 창 누락분 복구 추가.
  기존 L1 예보는 자동 복구 대상에서 제외하며, 예전 hs-only 예보를 자동 덮어쓰지 않는다.
  관측/네트워크 오류를 예보와 격리하고, 두 입력의 시작·끝·3시간 간격을 확인해 외삽을 막는다.
  관측 갱신 성공 후 최근 예보를 재채점한다. 실패한 한 사이클이 후속을 막지 않는다.
- `--dry-run`, `--backfill`(오프라인), `--catchup-days` 및 프로세스 잠금 추가.
- `scripts/manage_services.py`: macOS 사용자 launchd 서비스 설치/상태/제거.
  API는 127.0.0.1:8811에만 바인딩. 서비스는 사용자 로그인 뒤 재시작하며 Mac 수면/SSD 분리 중 계산하지 못한다.

## IMO 원문 대조에 따른 정정

출처: IMO MSC.1/Circ.1228 (2007), 2026-09-11 원문 확인.
https://wwwcdn.imo.org/localresources/en/OurWork/Safety/Documents/Stability/MSC.1-CIRC.1228.pdf

HANDOFF P3 및 PHASE18 단계 8의 "Hs > 0.04L을 모든 항목의 게이트로 사용" 제안은 기각한다.
이 파고 조건은 §4.2.2.1 연속 고파랑의 여러 조건 중 하나이며 §3.1 공통 전제가 아니다.
§4.2.3의 주기 일치 판정을 파고가 낮다고 일괄 끄지 않았다.
서프라이딩은 §4.2.1의 `1.8 sqrt(L) / cos(180-alpha)` [kn], 엄격한 135<alpha<225 범위로 정정했다.
파라메트릭 롤은 고유주기 및 그 절반의 근접을 모두 표시한다.
주기 근접 ±20%는 프로그램의 근사이고 IMO가 제시한 수치가 아님을 노출했다.
파장 범위는 §3.1.2의 0.6L~2.3L로 정정하고 슬래밍 확정 표현을 제거했다.
선박 길이는 수선간장이다. Tp를 대표 주기로 사용하는 근사·미계산 복원성·실선 검증 부재는 남는다.
