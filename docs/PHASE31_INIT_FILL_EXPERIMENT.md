## 0. PHASE28 의 분류 정정 — 결함은 둘이었다

PHASE28 §1 은 리드 0 영값 셀을 "스텐실 오염 26% / GFS-Wave 가 육지로 보는 마스크 불일치 74%"로 나눴다. **틀렸다.**
그 분류는 최근접 보간(`interp(method="nearest")`)의 NaN 을 "원천 육지"로 읽었는데, 최근접 보간은 **원천 범위 밖**에서도 NaN 을 낸다.

원천 경계 자료(boundary zarr)의 위도 범위는 **15.0~50.0°N** 이다(`core/types.py` `EAST_ASIA`). 예보 도메인은 **12.5°N** 부터다.
20260920T00 실측, 리드 0 해상 영값 1,287셀:

| 결함 | 셀 | 원인 | 영향 범위 |
|---|---:|---|---|
| **D1 범위** | 906 (12.5~15°N 해상 셀 **전부**) | 수집 범위가 예보 도메인 남단을 덮지 않는다 | 초기장·**바람**·**남쪽 경계** 모두 0. 남쪽 경계 행(12.5°N)은 72시간 내내 0.011 m 를 넘지 않는다 — 남쪽에서 오는 너울이 차단된다 |
| **D2 스텐실** | 381 (15°N 이상) | 겹선형의 가중 0 모서리가 육지 NaN → 0×NaN = NaN → `nan_to_num` 이 0 | 리드 0 (리드 3 h 이후 물리가 채운다). 연안 관측소 3곳 리드 0 편향 −0.56 m (PHASE28 §2 — 그 수치는 유효하다: 3곳 모두 15°N 이상) |

D2 는 방향성이 있다. scipy 는 격자점에 정확히 놓인 점에 대해 아래쪽 구간을 고르므로 가중 0 모서리가 **남쪽** 이웃이고,
원천 경도가 4e-6° 어긋나 **서쪽** 이웃이 가중 1.6e-5 로 들어간다. 그래서 육지 격자점의 북쪽·동쪽·북동쪽 해상 셀이 오염된다.

**이번 실험은 D2 만 다룬다.** D1 은 수집 범위를 바꿔야 하고(바람·경계·초기장이 함께 바뀐다), 과거 사이클은 원천이 사라져 재현할 수 없다. §5 에 다음 단계로 등록한다.

## 1. 후보와 불변식 — 결과 전 확정

`poseidon/scheduler/wave_inputs.py` `grid_wave_fields(ds, lats, lons, mode)`. 초기장과 매시 경계 갱신에 같은 함수를 쓴다.
자기검증(GFS-Wave 대비 로그 지표)은 기존 방식 그대로 둔다.

| 모드 | 동작 |
|---|---|
| `none` | 기존 방식 (운영 기본값, 비트 동일) |
| `seanorm` | **기존 보간값이 NaN 인 셀만**, 유한 모서리 가중을 다시 정규화한 겹선형. 유한 가중 합 < 0.05(`collocate.MIN_SEA_WEIGHT` 와 같은 값)면 채우지 않는다 — 가중이 거의 0 인 먼 모서리로 채우는 것은 외삽이다 |
| `seanorm_nn1` | `seanorm` 뒤 남은 NaN 셀을, 그 셀에 가장 가까운 원천 격자점의 **체비셰프 거리 1 이내(8방향)** 유한 격자점 중 가장 가까운 값으로. 등거리 허용치 = 원천 격자 간격의 1/1000(경도 4e-6° 어긋남이 만드는 가짜 거리차 무시). 등거리면 평균 |

### 진단 — 왜 실패했나 (판정과 별개)

G2 나머지 28개소 리드 0: 예보가 바뀐 관측소는 **2곳뿐**이다.

| 관측소 | 표본 | 평균 예보 차 | 이유 |
|---|---:|---:|---|
| KMA:22104 | 5 | +0.0150 m | PHASE28 §2 에서 영값 가중 0.03 — 채움 셀에 실제로 닿는다 |
| KMA:22101 | 5 | +0.0014 m | 영값 가중이 0 에 가깝지만 양수 |

나머지 **114건은 예보가 후보와 기존에서 정확히 같다**(차 0.0, 최대 |차| 0.0). 즉 "채움은 필요한 셀만 바꾼다"는 성질은 확인됐다.
G2 는 S3 를 영값 가중 ≥ 0.5 로 잘랐기 때문에, 그보다 작게 닿는 관측소가 나머지 집단에 남아 실패를 만들었다. **게이트 정의의 결함이다.**
그렇다고 사후에 고치지 않는다 — 결과를 본 뒤 정의를 바꾸면 사전 등록의 의미가 없다.

G3 리드 ≥ 12 h: 평균 예보 차 +0.0010 m, |차| 중앙 0.0006 m, 99% 0.0135 m, 최대 0.030 m. 기존 RMSE 0.3034 m 에 대해 후보 0.3033 m.
차이가 일관되게 아주 작아서(짝지은 표본이라 분산이 극히 작다) 구간이 0 을 배제한다. 등록 시 적어 둔 한계 그대로다 —
"0 을 포함"은 동등성 검정이 아니다. **효과는 실질적으로 무시할 만하다(RMSE 의 0.3%, 평균 차 1 mm)** 그러나 판정은 실패다.
평균 차가 양수(후보가 약간 크다)인 이유는 채운 연안 셀이 파고를 더 공급해서로 보이나, 원인 검정은 하지 않았다 `[가설]`.

## 4. 발견 — PHASE28 의 관측소 분석 갱신

S3 의 기존 리드 0 편향은 5사이클 짝지은 표본에서 −1.078 m 였다(66사이클 재구성 민감도에서는 −0.810, PHASE28 의 콜로케이션 표본에서는 −0.562).
표본 구성이 달라 세 값이 다르다 — 어느 하나를 대표값으로 쓰지 않는다. 방향(연안 3곳 리드 0 대폭 과소)은 셋 다 같다.
`seanorm_nn1` 이 `seanorm` 보다 S3 편향을 훨씬 더 줄인다는 것은 세 표본 모두 같다(66사이클 민감도: −0.810 → −0.331 → −0.137).
즉 **S3 결함의 대부분은 "가중이 0 에 가까운 육지 모서리"가 아니라 "가장 가까운 원천 격자점 자체가 육지인 셀"** 이다 —
그 셀들은 정규화로는 채울 수 없고 최근접 채움이 필요하다. 이것이 D2 의 실제 구성이다.

2. 새 사이클로 §3 끝의 G2'·G3' 를 사전 등록한 뒤 다시 평가한다. 표본이 15건인 G1 도 늘려야 한다 — 운영 예보가 쌓이면 S3 리드 0 표본이 사이클당 3건씩 는다
3. **D1(남쪽 12.5~15°N, 초기장·바람·남쪽 경계 0)** 은 이번 실험 밖이다. 분업 C5. 수집 범위를 넓혀야 하고 과거 사이클은 원천이 없어 재현할 수 없다
4. 기존 방식이 `dirpw` 를 산술 보간하는 결함(350°·10° → 180°)은 이번에 고치지 않았다 — 한 번에 하나(§6-11). 별도 후보로 등록할 것
5. 운영 표본에 두 방식이 섞이지 않도록, 후보는 `error_sample` 에 쓰지 않는다(`write=False`). 승급하면 `init_fill` 태그가 `features` 에 들어가고 `_engine_tags` 가 그것을 보게 해야 한다 — 요청 카드 발행 완료
