# Phase 30 — 결측 표시 정리

작성일: 2026-09-27 UTC. API 계약과 예보 산출물은 변경하지 않았다.

## 변경

콘솔의 파고 표시 기준을 한 곳으로 모았다. 지역 예보에서 `no_wave_energy` 상태이거나
Hs가 `0.011 m` 이하인 값은 화면에서 유효한 파랑값으로 쓰지 않는다. 이 기준은 지점 카드,
상세 패널, 수치표, 시계열 그래프, 항로 지도 색상에 적용된다.

전 지구 NOAA 원천은 이 화면 임계값으로 잘라내지 않는다. 전 지구 자료의 결측은 원천 상태와
API 응답의 `null`을 따른다.

이 단계의 목적은 마스크 결함 계열의 영값이 "잔잔함"으로 보이는 오해를 줄이는 것이다.
CSV 내보내기는 원본 분석값과 상태·결측 사유를 보존한다.

## 확인

```sh
node --experimental-default-type=module --test tests/web/*.mjs
```

추가 회귀 조건:

- 지역 예보의 `0.005 m` Hs는 시계열에서 유효 값으로 연결되지 않는다.
- 같은 값이라도 `source=global`이면 표시 계층에서 임의로 제거하지 않는다.
- 항로 지도 색상은 지역 영값 구간을 낮은 파고 색이 아니라 결측 색으로 그린다.

남은 표시 계층 작업은 PNG 파고 레이어의 sea-normalized 업스케일과 배경 지도 타일·글꼴 캐시다.
