# Phase 33 — 선박 조종의 지도 축척 해안선 판정

2026-09-27. Phase 32에서 선체가 육지와 부두를 그대로 통과하던 문제를 줄였다.

## 구현

- `/v1/helm/coast`는 선박 위치 중심 0.03° 창에 교차하는 Natural Earth 1:10m 육지 형상을 반환한다. 기존 `poseidon.twin.global_coast.land_index()`와 같은 고정 원천을 사용하며 ±180° 경계도 처리한다. 창 밖으로 이동할 때는 다음 창을 확보할 때까지 정지한다. 원천 실패나 형식 오류도 시작/계속 조종을 막는다.
- 화면은 실축척 선체 다각형 전체, 이전·다음 위치의 선체 꼭짓점 이동 경로와 육지 형상의 교차를 검사한다. 이동 시간은 최대 0.25초씩 나눠 고배속에서도 검사를 반복한다. 충돌로 정지하면 속력/회두율과 기관 명령을 0으로 만든다. 시작 위치도 같은 선체 겹침 검사를 통과해야 한다.
- 사용자가 불러온 OSM 부두·방파제·건물의 선/면 형상도 추가 장애물로 검사한다. `waterway=dock`은 수면이므로 제외한다. OSM을 불러오지 않은 구역은 시설 검사가 적용되지 않는다. 형상별 경계상자를 먼저 검사하여 많은 시설을 불러온 경우의 불필요한 선분 검사를 줄였다.
- 화면의 방법 설명과 항적 JSON 제한 사항을 실제 판정 범위에 맞게 수정했다.

## 검증

`tests/web/helm-navigation.test.mjs`: 자료 미확보, 선체-육지 겹침, 이동 경로 관통, OSM 방파제, 도크 수면 제외, 날짜변경선. `tests/integration/test_helm_coast_api.py`: 실제 서울 육지와 부산 연안 창, 위도 입력 검증. 전체 화면 Node 85개, Python 전체 476개 통과(API 전용 3개 포함). 로컬 API 재시작 뒤 `/v1/helm/coast` HTTP 200 확인; 실제 서울 좌표의 API 형상을 JavaScript 판정기에 넣어 육지 시작점 차단 확인. 브라우저에서 20배속 전진, 위치·속력 변화와 일시정지 확인.

## 게이트와 한계

이 단계는 **지도 축척 형상 교차 검사**이며 충돌 회피나 좌초 안전 판정이 아니다. Natural Earth 1:10m는 작은 섬·좁은 수로·최신 매립지를 놓칠 수 있다. OSM에는 미수록·잘못된 시설이 있고 공식 ENC/수로측량 자료가 아니다. 흘수·수심·조석·타 선박·해류·파랑 힘은 반영하지 않았다. 선박 조종 응답 계수 역시 실선 시운전 미보정이다. 따라서 산업용 선박 운항 판단 게이트는 통과하지 않았다. 다음 게이트는 지역별 공식 ENC 및 측심/수심 자료의 권한·범위 확인, 항만 접근 수로 검증, 실선 조종 시험 자료 보정이다.
