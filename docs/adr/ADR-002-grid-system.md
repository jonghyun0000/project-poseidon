# ADR-002: 격자 체계

**상태:** 승인 대기 · **날짜:** 2026-08-04 · **단계:** Phase 2

## 맥락
L1(해역 스펙트럼 파랑)·L2(연안 SWE) 엔진의 격자를 정해야 한다. WW3는 정규 위경도·SMC(Spherical Multiple-Cell)·비정형 삼각격자를 모두 지원하고, SWAN은 곡선·비정형, ADCIRC/SCHISM은 비정형 FEM이다.

## 검토한 대안
1. **정규 위경도 격자 + 육지 마스크** — 구현·검증 최단 경로, JAX 벡터화에 최적(균일 스텐실), Zarr 청크와 자연 정합. 단점: 해안 표현 계단형, 고위도 수렴.
2. SMC 격자 — 해안 자동 세분·극지 병합. WW3급 성숙 구현 필요, 인덱싱 복잡도가 JAX와 상성 나쁨.
3. 비정형 삼각격자(FEM/FVM) — 해안 충실도 최고. 그러나 격자 생성 파이프라인(OceanMesh2D급)이 별도 프로젝트 규모.

## 결정
- **L1 (동아시아 0.05°):** 정규 위경도 격자 + GEBCO_2025 기반 육지 마스크. 구면 메트릭(cos φ) 정확 반영.
- **L2 (연안 50–500 m):** 지역 등거리 투영(UTM/TM) 상의 **정규 직사각 격자** + 단방향(one-way) 둥지(nesting). L1→L2 경계는 스펙트럼/수위·유속 시계열로 전달.
- 비정형·SMC는 **Phase 9(최적화) 이후 재평가** 항목으로 기록만 남긴다 (성능·정확도 병목이 입증될 때만).

## 결과
- 격자 정의는 `poseidon/physics/grid.py`의 단일 `Grid` 자료형으로 통일 (위경도·투영 격자 공용 인터페이스).
- 스펙트럼 이산화 표준: **주파수 32개** (f₀=0.035 Hz, 비율 1.07 로그 분포, ~0.29 Hz까지), **방향 36개** (10° 간격) — WW3 운영 설정과 동일 계열.
- 수심은 셀 중심 평균 + TID 신뢰도 부가 변수로 저장.
