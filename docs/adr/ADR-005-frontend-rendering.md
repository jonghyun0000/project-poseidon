# ADR-005: 프런트엔드 렌더링 파이프라인

**상태:** 승인 대기 · **날짜:** 2026-08-04 · **단계:** Phase 2

## 맥락
전지구 3D 지구 → 1 m² 해수면까지 연속 줌, 히트맵·벡터장·입자 애니메이션·시간 슬라이더가 요구된다(브리프 §VISUALIZATION).

## 결정
| 계층 | 기술 | 역할 |
|---|---|---|
| 지구·지형 | **CesiumJS** | 3D 지구, 카메라, 지형/영상 타일, 시간축 |
| 데이터 오버레이 | **deck.gl** (CesiumJS 인터롭) | 히트맵(Hs·SST), 벡터장(바람·해류·파향), 입자 애니메이션(GPU) |
| 근접 해수면 | **WebGPU 커스텀 셰이더** (WebGL2 폴백) | 방향 스펙트럼 → Gerstner/FFT 합성 해수면, 거품·백파 (Tessendorf 2001 계열, 모델 스펙트럼 구동) |
| 앱 프레임워크 | **TypeScript + React + Vite** | 대시보드, 시간 슬라이더, 비교 모드, 경보 UI |

데이터 전달 규약:
- 격자 필드: 서버가 Zarr 청크를 **양자화된 바이너리 타일**(PNG16/WebP 무손실 또는 raw ArrayBuffer)로 변환 제공 (`/v1/tiles/{var}/{t}/{z}/{x}/{y}`), 클라이언트 셰이더에서 컬러맵 적용 — 서버 렌더링 이미지 타일보다 대역폭·상호작용 우수.
- 벡터장: 저해상 격자 서브샘플을 ArrayBuffer로 전송, deck.gl 입자 레이어가 GPU에서 적분.
- 스펙트럼(근접 줌): 카메라 위치의 최근접 스펙트럼 출력점 1–4개를 API로 수신, 셰이더 유니폼으로 파 성분 64–256개 합성.
- 정적 지도: OSM 폴리곤·Natural Earth → PMTiles 사전 빌드.

## 검토·기각한 대안
- Mapbox GL — 3D 지구·과학 데이터 오버레이가 주목적이 아니고 토큰 종속. OpenLayers — 2D 중심.
- Three.js 단독 지구 구현 — Cesium이 제공하는 지오이드·타일·시간축 재발명이 됨. Three.js는 WebGPU 해수면 씬 내부에서만 선택적 사용.

## 결과
- G-1의 `web/src/{api,components,layers,pages,shaders}` 구획은 **채택** (동일 구조 유지).
- 브라우저 요구: WebGPU 미지원 시 해수면 씬만 WebGL2 폴백, 나머지 기능 동일.
