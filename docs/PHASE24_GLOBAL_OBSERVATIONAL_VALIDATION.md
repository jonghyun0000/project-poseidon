# Phase 24 — 전 지구 원천의 실제 관측 대조

2026-09-12 KST. 전 지구 예보 제공 범위와 정확도 검증 범위를 분리한다.
지역 엔진의 RMSE를 NOAA 원천에 옮겨 붙이지 않고, 원천 예보와 실제 외부 관측의

## 정의·대조·품질 처리

- 원천은 NOAA GFS-Wave `HTSGW`, 관측은 NDBC `WVHT`(유의파고 m).
  PERPW와 부이 DPD는 서로 다른 정의이므로 주기·파향 점수를 만들지 않는다.
- 분석장 f0 제외, 예보값 보정·재학습 없음. UTC 명목 관측 행 중 ±30분 내
  가장 가까운 하나를 고른다. 동률이면 이전 시각이며 실제 행 시각과 오프셋을 CSV에 남긴다.
- NDBC 실시간 공개 자료는 자동 QC를 거친 제품이며 사후 확정 관측이나 개별 QC 등급이 아니다.
  MM·비유한 값·음수·40 m 초과를 제외한다. 이는 사전 정의한 넓은 이상값 범위다.
  모델 오차로 관측을 버리거나 평온한 반복 값을 임의로 제거하지 않는다.
- 같은 시각의 값이 충돌하면 그 시각 전체 제외, 값까지 동일하면 하나만 유지한다.
- 현재 위치 대신 `stationmetadata.xml`의 관측 당시 배치 좌표를 사용한다.
  이력이 없거나 겹치거나 이동일인 경우 제외한다. 날짜 단위 이력이므로 이동일 전체를 제외한다.
- 서빙과 같은 `global_forecast.spatial` 해양 마스크 정규화 보간을 쓴다.
  유효 해양 가중치 0.05 미만이면 결측, 육지 0을 끼워 넣지 않는다.
  Natural Earth 1:10 million 육지 판정도 동일하게 적용한다.
- 관측소 자동 선택은 현재 활동 목록에 의존하므로 이미 철거된 부이가 빠질 수 있다.
- 독립성은 Poseidon 보정·학습에 쓰지 않은 외부 실측과의 별도 대조를 뜻한다.
  NOAA 상류 동화·개발 표본으로부터의 완전한 독립성은 입증하지 않았다.

대조 후보 10,428쌍 = 채점 4,840 + 허용 시간 내 관측 없음 3,463 + 수신 실패 330
+ 배치 불명/전환일 181 + 육지 판정 1,333 + 해양 격자 결측 281.
마감 이후의 7개 **예보 파일**은 이 쌍 단위 합계에 섞지 않는다.
원본 관측 행 1,107,872건 중 파고 결측 433,795건, 사용 가능 파고 674,077건이다.
이 행 수는 실제 채점 표본 수가 아니다.

## 재현과 운영

```sh
.venv/bin/python -m poseidon.validation.global_audit \
  --start 20260903T00 --end 20260910T00 --cutoff 2026-09-11T16:00:00Z

# 원본 스냅숏과 예보 캐시의 SHA256을 확인하고 새 실행 ID로 재계산
.venv/bin/python -m poseidon.validation.global_audit \
  --resume 20260911T171729Z --offline
```

`data/validation/global/runs/<run_id>/`에 protocol.json, 원본 관측 gzip,
활동·배치 XML, 관측 manifest, pairs.csv, report.json을 보존한다.
`archive/<cycle>/`에 원본 GRIB·파생 NPZ·각각의 해시를 보존한다.
보고서에는 원본 파일 해시, 실행 코드 지문, 프로토콜과 CSV 해시가 있다.
재실행은 새 실행 ID를 만들며 기존 파일을 덮어쓰지 않는다.
전체 자료 실패나 실행 중 코드 변경은 공개를 차단하고 이전 보고서를 유지한다.
원본 33개 GRIB의 초기시각과 리드도 별도로 확인했다.

API `/v1/global/validation`, `report.json`, `pairs.csv`.
다운로드 URL에 실행 ID를 고정하므로 최신 결과가 바뀌어도 화면에서 본 보고서와 CSV가 일치한다.
`/console?view=validation&source=global`은 원천 검증을 표시하고 지역 검증은 기존 경로를 쓴다.
지점/항로 API의 적합성 판정을 산업용으로 승급하지 않는다.
지역 엔진 `uno2/none`, 지역 검증 DB, 운영 프로세스 PID 90164는 유지했다.
자동 반복 스케줄은 추가하지 않았다. 새 기간은 위 CLI로 명시적으로 수집한다.

## 위성으로 보완한 외해 표본

별도 규약 `sentinel3a-open-ocean-hs-v1`으로 Sentinel-3A 실제 센서 Hs를 대조했다.
780개 궤도 헤더의 실제 관측시각으로 34개 파일(18.9 MB)을 골랐으며 수신 실패는 0이다.
2026-09-03 05:34–09-11 00:30 UTC 관측, 33개 위성 통과에서 고유 30 km 구간 7,484개를
확보했다. 여러 예보 사이클과 대조한 쌍은 15,953개다. 관측 구간 평균 파고는 0.180–7.814 m다.
RMSE **0.380762 m**, MAE 0.245835 m, 편향 −0.040504 m.

**남극해와 큰 파고에서 오차가 커졌다.** 관측 4–6 m 구간 RMSE는 0.763450 m,
6–8 m는 0.954450 m였다. 이번 표본에서 가장 큰 절대 차이는 약 4.82 m이며,
20260903T00 +120 h 예보가 남위 64.012°, 동경 125.755°의 2026-09-08 00:25 UTC
관측 구간 6.427 m를 1.606 m로 예측한 사례다. 이는 확인한 한 사례이며 단일 사례로 일반 성능을 판단하지 않는다.

해안에서 50 km 이상인 자료를 사용하며, 원래 궤적에서 약 30 km 구간을 나눈 뒤
품질 조건을 통과한 3개 이상의 센서 표본과 같은 위치의 서빙 예보 평균을 대조한다.
RADS 센서 `swh_ku`만 사용하고 파일에 함께 들어 있는 모델 파고는 사용하지 않는다.
상세 품질 플래그·거리·시간·통계·원본 출처는 [위성 방법 및 재현 결과](PHASE24_SATELLITE_METHOD.md)에 있다.

관측 8 m 초과는 사전 품질 조건에서 제외했다(위반 792행, 그중 다른 선행 조건 통과 후 제외 745행).
따라서 극한파랑 정확도를 검증한 결과가 아니다. 실제 센서 전체 품질 보증, 모든 계절, 연안·해빙 조건,
미검증 리드와 지중해는 남아 있다. 고정 00/06 UTC 시간창의 표본은 지도에 보이는 일부 궤적에
모여 있으므로, 구역별 표본 존재가 해당 구역 전체의 검증 면적을 뜻하지 않는다.
서로 다른 UTC 시각·계절·위성과 더 긴 예측 기간의 독립 표본을 추가해야 한다.

부이·위성 점수를 합쳐 하나의 전 지구 RMSE로 만들지 않는다. 그 표본은 공간 규모와 분포가 다르다.
위성에는 독립 사건으로 가정한 신뢰구간을 표시하지 않는다.
API는 `/v1/global/validation/altimeter`이며 실행별 JSON/CSV를 다운로드할 수 있다.
최초 실행 `20260911T173905Z`, 오프라인 재현 `20260911T174146Z`에서 통계·좌표·CSV가 일치했다.
