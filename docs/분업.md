## 1. 왜 나누는가, 왜 경로로 나누는가

한 폴더를 둘이 고치면 같은 파일을 동시에 고칠 수 있다. 2026-09-27 이전에는 버전 관리가 없어서 충돌을 되돌릴 수 없었다.
이제 git 이 있다(기준선 커밋 `97784c0`). 그래도 충돌 자체를 줄이려고 **파일 경로로 소유를 나눈다.** 기능이 아니라 경로다 —
경로는 누가 봐도 판정할 수 있다.

두 에이전트의 지금까지 강점도 그렇게 갈린다.
- **Claude**: 물리 엔진, 검증 통계, 운영 루프. 측정 경로 결함 찾기(`docs/LESSONS.md` A·B)
- **Astra**: 콘솔 UI, 항로·항구·전 지구 원천, API 계약, 재현 가능한 보고서(PHASE 20~26)

## 3. 작업 절차 — 둘 다 지킨다

1. **시작 전**: `git status` 가 깨끗해야 한다. `git log --oneline -10` 으로 상대가 무엇을 했는지 읽는다
2. **남의 경로는 고치지 않는다.** 고쳐야 하면 §6 에 요청 카드를 쓰고 멈춘다
3. **공유 파일은 작게, 따로 커밋한다.** 고치기 직전에 `git log -1 -- <파일>` 로 마지막 변경을 확인하고 파일을 다시 읽는다
4. **커밋 = 작업 하나.** 메시지 첫 줄은 `[claude] C1 …` / `[astra] A1 …` 처럼 작업 ID 로 시작한다. 이모지 금지
5. **테스트**: 커밋 전에 `.venv/bin/pytest -q -m "not scientific"`. `engines/` `physics/` `scheduler/` 를 건드렸으면 `-m scientific` 도(약 2~3분)
6. **서비스**: 운영 루프(`local.poseidon.operational`)는 Claude 만 재시작한다. Astra 는 API 재시작 가능 — 재시작했으면 커밋 메시지에 적는다
7. **무거운 계산은 운영 예보와 겹치지 않게.** 운영 루프가 예보 중일 때 전 지구 검증 같은 큰 배치를 돌리면 예보 시간이 늘어난다(실측 25~46분, 문서값 15분 — 원인은 C2 에서 잰다). 돌리기 전에
   `tail -3 ~/Library/Logs/Poseidon/operational.service.log` 로 `L1 wave run` 직후인지 본다
8. **끝나면**: PHASE 문서에 결과(기각·실패 포함), `HANDOFF.md` 맨 위 "최신 변경"에 3~6줄, 이 문서의 카드 상태를 갱신한다

목표

범위 — 건드려도 되는 파일
  `AGENTS.md` 의 §3 지형과 §5 도메인·데이터 사실만. `HANDOFF.md`. `docs/api/`. `tests/integration/`

  3. `AGENTS.md` §3·§5 의 수치·파일 목록을 실측으로 갱신한다(라우트 수, 줄 수, 표본 수 — 조회 시각 병기)

  - `HANDOFF.md` 현재 상태 층에 "아무것도 돌고 있지 않다" 같은 과거 서술이 남아 있지 않다

### A2. 표시 결함 4건 — `대기` (A1 다음)

목표
  화면이 사실과 다르게 보이는 곳 4개를 고친다.

왜
  해운 판단 화면에서 "없는 값"과 "0"을 구분하지 못하면 결측이 무풍·잔잔한 바다로 읽힌다.

범위
  `poseidon/api/` `web/public/` `tests/`(해당 테스트)

요구 사항
  1. **바람 결측이 0 으로 나간다.** `api/app.py` 의 `np.nan_to_num(w.u10…)`·`v10`(2026-09-19 기준 584–585행 부근),
     `api/global_ocean.py` 의 `nan_to_num`(97행 부근). 결측은 `null` 로 보내고 화면은 그리지 않는다
  2. **신선도 임계가 사이클 주기와 안 맞는다.** `FRESH_REALTIME_H = 9.0` 인데 사이클은 6시간 주기다. 근거와 함께 재정의하고,
     화면 문구를 "최신"이 아니라 "이 산출물의 사이클 + 다음 사이클 예정 시각"으로. 코드는 `realtime/delayed/historical/replay`
     4종이다 — 문서가 3단계라고 쓴 곳이 있다(`docs/OPERATIONS.md` 는 Claude 소유 — 고쳐야 하면 §6 요청)
  3. **MapLibre 가 두 버전(`@5`, `@5.7.1`)으로 섞여 있고 CDN 에서 받는다.** 한 버전으로 고정해 `web/public/vendor/` 에 두고
     라이선스 파일을 함께 둔다. 선상 저대역·오프라인에서 화면이 비지 않게 하려는 것이다
  4. **표시 경로의 육지 번짐.** `field_hs_png` 의 `ndimage.zoom(np.where(sea, hs, 0.0), order=3)` 이 육지 0 을 연안 해상 셀로
     번지게 한다. 값과 마스크를 각각 업스케일한 뒤 나누는 sea-normalized 로. **이것은 이 프로젝트에서 여섯 번째 마스크 결함이다**
     (`docs/LESSONS.md` A-1) — 육지에 인접한 해상 셀이 들어간 테스트를 반드시 둔다(전-바다 테스트로는 못 잡는다)

완료 조건
  - 4건 각각 회귀 테스트, 4번은 "육지 인접 해상 셀의 표시값이 원 격자값 대비 −5% 이내"
  - 인라인·외부 JS 전부 `node --check` 통과(`docs/LESSONS.md` G-2 — 주석이 괄호를 먹어 화면 전체가 죽은 전례)
  - 실제 브라우저에서 창을 앞에 둔 채 확인(G-1 — 숨김 창에서는 지도가 에러 없이 멈춘다)

### A3. 항로 비용 함수 연결 — `차단: C3 이후`
