국가별 실제 항구를 추가한다. 기존 Phase 31 초기장 실험·평가 파일은 보존했다.

## 구현과 사용

`/console?source=global&view=helm`에 선박 조종 메뉴를 추가했다.
컨테이너선·VLCC·LNG선·자동차선·로로여객선·대양여객선·탐사선·쇄빙선·준설선·예인선·
작업자 이송선·순찰선 12종. 9개 명명된 실선과 3개 실제 건조 시리즈를 참조한다.
길이·폭과 출처·확인일은 `ships.js`에 기록하고 화면에서 출처를 연다.
선체 길이·폭은 지도 실축척, 상부 구조·높이·선형은 유형별 개념 모형이다.
선박의 실제 AIS 위치나 실선 외형의 완전 복제는 아니다.

- 기관 전진/중립/후진, ±35° 조타, 선박별 다른 응답 시간.
- W/S 기관, A/D 조타, X 중립, C 타 중앙, Space 일시정지.
- 1×/5×/20× 시간 배속, 추적 카메라, 입체/평면, 시작점 선택/초기화.
- 속력·선수방위·회두율·거리·경과시간과 날짜변경선 분리 항적.
- 숨긴 탭·창 초점 이탈·다른 메뉴 진입 시 일시정지.
- JSON 기록에 참조선 제원/출처, 조종 가정, 원점, 항구 참조, 단위와 입력을 보존.
  최근 최대 12,000개 표본과 저장 시점만 내보낸다. 잘린 기록은 sample_window.truncated 표시.
- 기존 NOAA 지점 조회로 현재 위치 파고를 따로 조회한다. 좌표·유효시각·사이클을 표시하고
  현재 시각이 예보 범위 밖이면 값을 만들지 않는다. 환경 힘으로 사용하지 않는다.

## 조종 계산의 자격

이 구현은 조작용 운동학 데모다. 지수 응답으로 명령 속력·타각·회두율에 접근하고,
구면 위에서 위치를 이동한다. 회두계수와 응답 시간은 실선 시험에서 얻지 않았다.
실제 선박 운동 방정식이나 인증된 조종 성능이라고 주장하지 않는다.
예인선의 아지무스 추진도 공통 입력으로 단순화했다.
중립은 점진 감속이며 일시정지는 시뮬레이션 시간 정지다.
파랑력·해류·선체 충돌·수심·흘수·접안·연료·자동 항행은 미계산이다.

## 국가별 항구와 실제 형상

기존 UN/LOCODE·NGA 카탈로그(234개 국가·지역, 18,582개 위치·시설)를 조종 화면에서
국가 필터·검색·페이지 이동으로 조회한다. 세계 항구 화면에서도 조종 화면으로 연결한다.
대표점을 배의 시작점이나 선석으로 변경하지 않는다. 항구 선택 후 지도에서 시작 위치를
따로 지정해야 한다. 좌표 없는 항구는 지도 이동을 비활성화한다.

OSM 실제 way 좌표·식별자를 보존하여 부두·방파제·건물·dock을 겹쳐 그린다.
원형이 열린 선이면 닫힌 다각형으로 만들지 않으며, 노드 결측도 임의로 채우지 않는다.
등록된 구조물 위에 시작점을 놓는 것은 거부하지만, 이것은 전체 육지/충돌 검사가 아니다.
시설 요청 영역은 지도 중심의 0.01° × 0.01°이며 지도에 점선 범위를 표시한다.
국가별 동일한 가상 항구를 생성하지 않는다.

12개국 대표점 주변 **6,307개 OSM 형상**을 로컬 스냅숏으로 확보했다.
이는 항만 전체나 항만 소유 시설 수가 아니다. 주변 일반 건물도 포함한다.

원본 SHA256을 기록한다. 원본은 `data/static/harbors/`에 보존했다.
OSM 파생 데이터는 ODbL 1.0이며 출처·라이선스를 동봉했다.
배경 타일은 화면에 보이는 것만 읽으며 일괄 다운로드하지 않았다.

로컬 스냅숏이 없는 지도 구역은 사용자 요청 시 OSM 읽기 API로 조회한다.
네트워크 오류·시간 초과·결측은 명시하며 좌표나 시설을 합성하지 않는다.
선택 항구가 바뀌면 이전 요청을 취소하고 이전 형상을 지운다.
처음 시도한 Overpass 원천은 HTTP 406/시간 초과여서 채택하지 않았다.
OSM map JSON 원천은 실제 200 응답과 브라우저 CORS 조회를 확인했다.

**전 세계 항구의 실제와 동일한 디지털 트윈은 미완료다.**
OSM way 일부만 읽으므로 관계형 multipolygon 시설, 전체 항만 경계, 실제 높이,
수심·선석·항만 규제·실시간 교통을 전부 재현하지 못한다. 공식 ENC·시설 GIS·수심 조사와
사용 권한, 실선 조종 시험 자료가 다음 정확도 단계의 입력이다.

## 재현과 검증

```sh
PYTHONPATH=. .venv/bin/python scripts/build_harbor_snapshots.py
node --experimental-default-type=module --test tests/web/*.mjs
.venv/bin/python -m pytest -q -m 'not scientific'
```

- Node 전체 81개 통과(새 조종/형상 검증 10개).
- Python 기존 회귀 383개 통과, scientific 91개는 이번 실행에서 제외.
  예보 엔진은 변경하지 않았으며 실선 정확도 시험으로 해석하지 않는다.
- 브라우저: 실축척 선체 표시, 전진·우현 조타, 시간 배속, 일시정지,
  모바일 예인선 선택/전진, 부산 검색 및 OSM 형상 로컬/실시간 조회를 확인했다.
- 390 × 844 모바일 document/root 너비 390: 가로 넘침 없음.
- 키보드 W 입력의 기관 5% 반영 확인. JSON 다운로드 파일을 실제로 읽어
  schema_version, 참조선, 단위, sample_window와 제한 사항이 보존됨을 확인했다.
- 조종 위치는 지도 표시와 수치 안정성을 위해 위도 ±80° 안에서 선택한다.
- 초기 브라우저가 이전 app.js를 재사용해 새 메뉴가 비었던 문제를
  새 진입 모듈 버전으로 해결했다.
- 서비스 재시작·운영 예보 재생산·API 계약 변경 없이 정적 콘솔 파일을 제공한다.
