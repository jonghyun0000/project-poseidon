These JSON extracts preserve source coordinates and OSM way IDs. Each snapshot
records the catalog reference point sector, original request URL, retrieval time
and SHA-256 of the raw response. The collection is a database derived from OSM
and remains available under ODbL 1.0. No background raster tiles are bundled.

Each extract covers only a 0.01 by 0.01 degree sector around an official catalog
reference point. It is not a complete port, a depth survey or a navigational chart.
Buildings in that sector are not necessarily port-owned facilities.
Reproduce with scripts/build_harbor_snapshots.py.
