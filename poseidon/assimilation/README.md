# poseidon.assimilation

Hs 관측 동화. 방법 태그 **`oi-hs-v1`** — 최적내삽(OI)으로 Hs 를 분석하고, 그 배율을
ECMWF IFS 식 2-파라미터 변환으로 스펙트럼 E(f,θ) 에 되돌린다.

**기본값은 꺼짐이다.** `wave_cycle --assimilate none`(기본)은 동화 코드를 타지 않고
동결 엔진(uno2/none) 결과를 **비트 동일**로 재현한다 — 20260821T00 에서 확인
(`np.array_equal(ctrl.hs, ident.hs) == True`).

## 파일

| 파일 | 역할 |
|---|---|
| `params.py` | 전 파라미터 + 실측 근거·문헌 대조. **수치를 바꾸려면 여기부터 읽을 것** |
| `observations.py` | KMA/NDBC Hs 관측 로드 (qc_flag==0, ±30분 창, 중복 제거) |
| `bias.py` | 관측소 지속 편차 b_s 의 leave-one-cycle-out 수축 추정 |
| `oi.py` | Hs 공간 OI — 상관함수·Gaspari-Cohn 국지화·시선제약·해양 정규화 H |
| `spectral.py` | Hs 배율 q → E(f,θ) 재척도 (풍파/너울 분기, 로그주파수 시프트) |
| `cycle.py` | 오케스트레이션 + zarr attrs 각인 |

## 설계 판정 (기각된 대안)

- **EnKF 기각**: L1 1런 4분 × 20~50 멤버 = 사이클당 80~200분. 6시간 주기에 불가.
- **EnOI 기각**: 정적 앙상블을 만들 아카이브가 11 사이클뿐.
- **3D-Var 기각**: E 공간 B 행렬 1.76e7 자유도를 명세해야 하는데 관측이 41개 스칼라뿐이라
  해가 전적으로 B 로 결정된다 = OI 와 같은 가정에 비용만 10~100배.

(이 README 는 ADR-001 의 "EnKF 및 4DVAR" 계획을 대체한다. 위 판정은 실측 비용
근거이며, 표본이 늘면 재검토 대상이다.)

## 반드시 지킬 것

1. **육지 마스크** — 이 프로젝트에서 네 번 반복된 결함이다. 관측↔격자 사상은
   `collocate.sea_normalized` 를 재사용하고, 증분은 sea 셀 + 경계 링 제외에만 넣는다.
   경계 링은 `analyse_hs` 와 `energy_ratio` **양쪽**에서 막아야 한다 — 평활이 링으로
   번져 6.8e-4 m 가 샌 적이 있다(회귀 테스트 있음).
2. **도메인 밖 관측** — `corner_weights` 는 밖의 점을 가장자리 셀로 **클램프**한다.
   명시적 경계 검사 없이 쓰면 태평양 부이가 도메인 가장자리에 동화된다(회귀 테스트 있음).
3. **표본 오염 금지** — 동화 산출물은 다른 `source_id`(`spectral_wave-L1-da`)와 다른
   파일명으로 기록된다. `collocate.py` 는 `source_id == "spectral_wave-L1"` 만 집으므로
   대조군 표본에 섞이지 않는다. **단, collocate 는 아직 `assimilation` attrs 를 읽지
   않는다** — features 에 동화 태그가 남지 않는다(다음 단계 과제).
4. 운영 승급은 사전 등록 게이트 통과 후에만. 현재는 **미승급 · 평가 단계**다.
